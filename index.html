Conoce las amenazas digitales

🎣

Phishing

Correos electrónicos y mensajes fraudulentos que intentan suplantar instituciones o empresas para obtener contraseñas y datos personales.

🦠

Ransomware

Software malicioso que bloquea o cifra archivos y exige un pago para intentar recuperarlos.

🔓

Robo de credenciales

Acceso no autorizado a cuentas mediante contraseñas comprometidas o engaños.

⚠️

Malware

Programas diseñados para dañar dispositivos, robar información o comprometer sistemas.
